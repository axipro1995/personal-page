## Caveats
- Compiled from public vendor release notes, changelogs, GitHub release pages, and security advisories via web search rather than direct verification of every CVE — confirm exact CVSS scores, affected versions, and patch availability against vendor advisories before acting. In particular, Oracle's full Java-SE-specific CVE risk matrix for the 2026-08-18 CSPU could not be retrieved via search (403 on the verbose advisory page) and should be pulled directly/authenticated before final remediation planning.
- "Within the window" is judged against 2026-08-13 to 2026-08-20. Several items are reported as flagged-but-outside (e.g. React Native 0.87.0 GA on 08-11, MongoDB's 27-vulnerability disclosure on 08-11) because they are highly relevant and fell only 1–2 days before the window opened.
- The Netty entry reconciles a data conflict: last week's report already listed 4.1.137.Final/4.2.17.Final as released 2026-08-06/08-04; this week's research surfaced a 2026-08-17 date for the same version numbers, which is most consistent with a security-advisory (CVE-2026-59903) disclosure date rather than a new tagged release — treat the fix as already shipped in the versions reported last week, with the advisory itself newly public this window.
- MongoDB's version numbering (Server 7.0.40/8.0.29/8.3.8 fixing the 08-11 disclosure) and Elasticsearch's exact CVE/ESA numbers for 9.5.2 varied slightly across secondary sources; treat the reported version floors as directionally correct and confirm against MongoDB's and Elastic's own security bulletins before patch sign-off.
- Managed cloud services (BigQuery, GCP/AWS features, Cloudflare, Firebase, PayPal, Apple Pay) don't version the same way as OSS libraries — entries reflect the most recent dated announcements found, not a single canonical "latest version."
- This report closes out two "watch next window" items flagged in the 2026-08-12 report: PostgreSQL's quarterly release landed exactly on 2026-08-13 as forecast, and Oracle's first monthly CSPU landed exactly on 2026-08-18 as forecast.
